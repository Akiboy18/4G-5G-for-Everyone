# 4G-5G-for-Everyone
This repository serves as a living document of my journey through 4G and 5G

## What is 3GPP ? 
> The 3rd Generation Partnership Project (3GPP) is a global collaboration that creates technical specifications and standards for mobile telecommunications

### What 3GPP Does

* **Sets Global Standards**: It unites regional telecommunications groups to build unified wireless protocols.
* **Covers Generations**: It developed the standards for 2G (GSM), 3G (UMTS/HSPA), 4G (LTE), and 5G (5G NR), while working on future network evolutions.
* **Defines Architecture**: It designs the radio access network, core network, and service capabilities to ensure devices work worldwide.

### How It Works

* **Founded**: Established in December 1998 by regional standards organizations.
* **Member-Driven**: Composed of individual industry experts working in technical specification groups.
* **Releases**: Work is organized into numbered "Releases" that add new features and performance boosts over time
